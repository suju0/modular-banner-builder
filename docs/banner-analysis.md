# 컬리 배너 패턴 분석

## 분석 대상
마켓컬리(Kurly) 프로모션 배너 9종 분석

## 식별된 레이아웃 유형

### Type A: 센터 페스타 (Center Festa)
- **대표**: Beauty Kurly Festa (퍼플 배경)
- **특징**: 중앙 정렬, 장식 요소(원형, 리본, 스파클), 세일/이벤트 키워드 중심
- **구성**: 이벤트 태그 + 메인 타이틀 + 할인율 + 서브 카피 + 기간
- **사용처**: 대규모 시즌 세일, 페스타, 기획전

### Type B: 좌측 텍스트 + 우측 이미지 (Left-Right Split)
- **대표**: 컬리 과일 가게 (민트 배경 + 멜론), 이 주의 특가 (나무 배경 + 장바구니)
- **특징**: 텍스트 좌정렬, 상품 이미지 우측, 가격/혜택 강조
- **구성**: 타이틀 + 서브 카피 + 가격/할인 정보 + 기간 | 상품 이미지
- **사용처**: 단일 상품/카테고리 특가, 주간 추천

### Type C: 포토 오버레이 (Photo Overlay)
- **대표**: Kurly Fresh Festival (식재료 사진), Seoul Gourmet Guide (음식 사진)
- **특징**: 풀 배경 사진 위에 그래디언트 오버레이 + 텍스트
- **구성**: 타이틀 + 영문 서브타이틀 + 혜택 정보 + 기간
- **사용처**: 프리미엄 기획전, 시즌 테마, 브랜드 감성 강조

### Type D: 클린 프로덕트 (Clean Product)
- **대표**: 선물하기 오픈 기념 (보자기), 마켓컬리 브랜드 (흰 배경 + 산포된 상품)
- **특징**: 깔끔한 단색 배경, 상품들이 자연스럽게 배치, 여백 활용
- **구성**: 타이틀 + 설명 텍스트 + 상품 이미지 배치
- **사용처**: 브랜드 캠페인, 서비스 론칭, 시즌 선물

### Type E: 콜라보/브랜드 (Collaboration)
- **대표**: JAM × Kurly (듀얼 로고), 7일간의 혜택 (N마트 브랜딩)
- **특징**: 협업 브랜드 로고 병렬, 중앙 정렬, 쿠폰/혜택 뱃지
- **구성**: 브랜드 로고 + 타이틀 + 혜택 뱃지 + 일시/기간
- **사용처**: 브랜드 콜라보, 외부 제휴, 채널 프로모션

## 텍스트 스타일 패턴

- **메인 타이틀**: Bold/Black, 한글 24~40px 상대 크기, 자간 -0.02em
- **영문 타이틀**: Bold/Black, 한글보다 약간 큰 사이즈, 자간 0~0.02em
- **서브 카피**: Medium/Regular, 메인의 약 40% 크기
- **기간/가격**: Regular/Medium, 서브보다 작거나 비슷, 간격 넓은 편
- **할인율**: Black/Heavy, 강조색(accent), 메인과 비슷하거나 더 큰 크기

## 자동화 시사점

1. **레이아웃 × 테마 × 모듈 조합**으로 대부분의 배너 커버 가능
2. **텍스트 자동 사이징** 필수 — 같은 슬롯이라도 콘텐츠 길이에 따라 크기 조절
3. **이미지 영역**은 레이아웃에 따라 위치가 고정되므로 슬롯 기반 접근이 효과적
4. **장식 요소**는 레이아웃 타입에 종속 (페스타=장식 많음, 클린=없음)
5. **컬러는 독립 레이어** — 같은 레이아웃+모듈이라도 테마만 바꿔 다른 분위기 연출
